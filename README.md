# 📁 File Organizer

Небольшой учебный проект на Python, который автоматически сортирует файлы по папкам в зависимости от их расширения.

Проект создан для изучения работы с файловой системой Python, в частности `pathlib` и `shutil`.

## ✨ Возможности

* 🔍 Поиск файлов в указанной папке
* 📂 Автоматическое создание папок для категорий
* 🖼 Сортировка изображений
* 🎬 Сортировка видео
* 📄 Сортировка документов
* 📦 Сортировка архивов
* 🎵 Сортировка музыки
* 💻 Сортировка программ
* 📁 Перемещение неизвестных типов файлов в отдельную категорию
* ⚠️ Проверка существования файла перед перемещением

## 📂 Категории

| Категория | Расширения                               |
| --------- | ---------------------------------------- |
| Images    | `.jpg`, `.jpeg`, `.png`, `.gif`, `.webp` |
| Videos    | `.mp4`, `.avi`, `.mkv`, `.mov`           |
| Documents | `.pdf`, `.docx`, `.doc`, `.txt`, `.xlsx` |
| Archives  | `.zip`, `.rar`, `.7z`, `.tar`            |
| Music     | `.mp3`, `.wav`, `.flac`                  |
| Programs  | `.exe`, `.msi`                           |

Файлы с неизвестными расширениями попадают в категорию `Other`.

## 🛠 Используемые технологии

* **Python 3**
* `pathlib` — работа с путями, файлами и папками
* `shutil` — перемещение файлов
* `dict` — хранение категорий и расширений

Дополнительные библиотеки устанавливать не требуется.

## 📦 Установка

Склонируйте репозиторий:

```bash
git clone https://github.com/lercpp/file-sorting.git
```

Перейдите в папку проекта:

```bash
cd FileOrganizer
```

Проверьте установленную версию Python:

```bash
python --version
```

или в Windows:

```bash
py --version
```

Перед запуском на реальной папке рекомендуется протестировать программу на отдельной директории.

Программа использует `shutil.move()`, поэтому файлы **реально перемещаются** между папками.
